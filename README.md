## 🚀 Featured Projects

### 1. 🚌 Smart Bus Tracking System

A real-time bus tracking application designed to help users track bus locations and manage bus routes.

**Key Features**
- Live bus location tracking using browser geolocation.
- Interactive maps using React Leaflet and OpenStreetMap.
- Bus and route management.
- Backend APIs for handling bus and route information.
- Separate frontend and backend applications.

**Tech Stack:** Java, Spring Boot, React, JavaScript, OpenStreetMap, Leaflet.

**Repositories:**
- [Backend Repository](https://github.com/Ambik08/smartBusTrackingBackend)
- [Frontend Repository](https://github.com/Ambik08/smartBusTrackingFrontend)

### 2. 📚 CRHub – Class Representative Management System

A web-based application designed to simplify academic communication and class management between class representatives and students.

**Key Features**
- Subject and academic material management.
- Upload and access PDF documents.
- Publish important class notices.
- Student and roll number management.
- Task management for class activities.

**Tech Stack:** Java, Spring Boot, Spring Data JPA, MySQL, React, Vite, Tailwind CSS, DaisyUI.

**Repositories:**
- [Backend Repository](https://github.com/Ambik08/CRHubBackend)
- [Frontend Repository](https://github.com/Ambik08/CRHUBfrontend)
